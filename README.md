# Vetrix-Graduation-Project-2027-
Vetrix is an AI-powered, CFR 21 Part 11 compliant Laboratory Information Management System (LIMS) designed for veterinary pharmaceutical QA/QC labs. Features include Computer Vision (YOLO/OCR) for legacy instrument reading, RAG Assistant for Pharmacopoeia standards, and Predictive ML for Supplier &amp; Batch Risk Scoring.
